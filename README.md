# erasmus\_student\_guide

A student-powered mobile guide for Erasmus students.

## Team members

- Aldiyar Kairolla
- Yusuf Taskin
- Engin Yurt

## Initial Idea

This mobile application aims to help Erasmus students adapt to life at a new university by reading about other students’ experiences.

The application provides structured information about courses and university life.

With this student-powered guide, users will be able to browse information by country, university, department, and course. Both local and exchange students can share their experiences.

The initial version will focus only on Lodz University of Technology (Politechnika Łódzka). We plan to gradually include more universities through student contributions.

## Development Environment

- Android Studio
- Kotlin
- Jetpack Compose
